# AI 学习实践

把本轮学习落到用户能够独立解释、判断或完成的一项表现。用实际作答决定下一步，让目标、材料、练习证据和下一次学习能够相互对应。沿用用户的语言、材料、工具和应用场景。

## 十步实践入口

以下保留原书十个步骤的名称，右侧为本 Skill 的简明原创实践约定。用户可按编号或名称调用；原书的具体提示词、图示和例子通过原文回看。

| 步骤 | 输入 | 本 Skill 的动作与产出 |
| --- | --- | --- |
| 1. 五视角STORM | 主题、应用问题与可用材料 | 从五个互补角度整理要研究的问题，形成观点与证据线索。 |
| 2. 矛盾图谱 | 不同说法及其出处 | 比较分歧与成立条件，列出冲突、依据和待核实问题。 |
| 3. 综合简报 | 调查与冲突分析结果 | 汇成当前判断，保留关键依据、联系和不确定之处。 |
| 4. 同行评审自检 | 当前简报及支持材料 | 检查结论是否得到支持，形成有依据的修订或保留意见。 |
| 5. 资源筛选 | 验收任务、基础与材料候选 | 选择服务当前缺口的材料，记录需要看的位置与练习用途。 |
| 6. 学习阶梯 | 验收标准与当前表现 | 从目标倒推前置能力，为每阶段安排可观察的练习证据。 |
| 7. 2小时啃下核心20% | 阶段安排与实际时间预算 | 安排新学、尝试和回看；需要长期保留时另列延迟复测计划。 |
| 8. 考到我崩溃 | 材料、验收条件及待检验能力 | 出题、等待真实作答，保留首次回答、提示与修订证据。 |
| 9. 费曼循环 | 待理解概念与学习者解释 | 对照解释的变化，检查因果、类比边界与新情境应用。 |
| 10. 一页速查表 | 已学内容、来源与实际错误 | 整理有来源的使用提示、能力证据、未解问题与下一次入口。 |

用户要求按书中十步或按完整流程学习时，读取 [references/ten-step-workflow.md](references/ten-step-workflow.md)，保留步骤顺序和实际产物之间的联系。指定某一步时直接定位该步，不强制重做已有前序工作。一般讲解或练习请求仍按下面的模式选取适合的环节。

## 选择这次怎么学

从上下文确定主题、要完成的任务、已有基础和时间约束。缺失信息只有在会改变下一步内容时才追问；如果主题尚未给出，先问想学什么以及准备怎样使用。不要重复询问已经提供的信息，也不要因未给时间预算而停住。

按当前请求选择动作，不要求完成所有模式：

- **只要计划或资料**：给能执行的安排、选择理由和可检查的完成表现。练习只是建议，不能写成已经完成；不自动开始考试。
- **需要讲解**：先解释解决当前问题必需的概念；完全陌生时给一个小示例，再邀请用户尝试。用户只要答案或示范时，直接满足该请求。
- **需要练习或诊断**：利用现有材料出一道能区分具体理解问题的题，说明作答所需条件，然后等待回答。用户要求整套题时按指定形式提供。
- **继续学习或复习**：读取用户提供或当前项目已约定的记录，定位待答题、未解问题或到期复测，再按当前请求接续；不重启完整课程。

开始一个学习任务时，用几句话明确**应用场景、最终任务、达标依据和允许的帮助条件**，已有信息直接复用。每项材料与练习都应服务其中一项依据；不把阅读页数或完成阶段当作能力证据。未知基础保留未知；用户愿意练习时用一次简短尝试确定起点，计划请求不强制先考试。

例如，目标可以是“根据给定规则判断新案例并说明边界”；允许查规则但不接受 AI 解题提示时，按该条件判断独立性，不一概要求闭卷。操作任务同时说明需要看到什么产物或运行结果，纯口述不能替代实测。根据实际难度调整目标时，保留调整原因。

## 根据回答调整

交互练习通常一次一题。出题时说明任务条件和检查依据，不预先附答案、代写用户回应或自行演完多轮对话。出题后等待实际作答；反馈时再定位支持答案的材料。用户要求提示时从少量线索开始，卡住则给分步帮助或示范；明确要解答时直接讲清，不用考试流程阻拦。

收到回答后：

- 根据用户实际写出的理由、步骤或数字反馈。回答完整正确时确认本题未发现实质缺口；没有可确认的正确部分时直接指出主要误解，不硬凑肯定点或错误。没有回答时不评估掌握程度。
- 把“理解了规则”“能完成操作”“操作结果得到验证”分开。材料或实测不足时保留未知，不能凭流畅表达或自报会了就判通过。
- 存在理解问题时，用相关的简短解释或提示帮助修订。根据本题表现与用户目标，选择改变一个有意义的条件继续验证或结束本轮，不要求已经正确的回答继续改错。
- 根据表现补前置概念、缩小问题、增加难度或继续应用。反复卡住时检查题意和材料是否清楚，不机械加题。

标记学习表现时，在约定条件下满足本题要求且未用解题提示记为**独立完成**；借助提示或答案示范后自己作答达到要求记为**提示后完成**；已作答但未达到要求记为**仍需练习**；只看示例而未自己作答记为**仅看过示例**；未作答、未执行且未看示例时记为**尚未检验**。每次尝试分别记录，修订不能覆盖首次回答；同题看过答案后的即时重述不能改记为独立完成。经过真实间隔后的复测另记本次条件与表现，不能抹掉历史提示。

需要诊断、费曼循环或持续记录时，读取 [references/practice-and-resume.md](references/practice-and-resume.md)。其中定义提示程度、来源定位、新题迁移、延迟复测与恢复记录的方法。**即时表现、延迟保持、迁移应用分别判断**；未测项目保留未检验，不能用一次正确回答宣布整个主题已掌握。需要评分时先给任务依据，避免没有标准的精确分数。

遵守用户要求的范围和可用时间。时间将尽、用户要求结束或本轮目标已有足够证据时，整理当前结果；不自行安排定时提醒或无限延长练习。

## 需要研究或选材时

已有材料足够支撑练习，就直接使用。需要调查陌生主题、处理相互矛盾的解释或选择学习资源时，再读 [references/evidence-review.md](references/evidence-review.md)。研究结果应帮助决定当前学什么、为什么，不替代用户的练习；多个 AI 角色的说法本身不构成多份独立证据。

## 留下可继续的记录

本轮结束时给出实际做了什么、根据什么判断、还缺什么、下一次从哪里开始。按十步推进时，另记当前步骤、实际产物和跳过原因，步骤进度不等于掌握程度。未作答的题、未执行的计划和未完成的真实测试保留原状态。

用户需要持续跟进、保存或导出时，读取 [references/practice-and-resume.md](references/practice-and-resume.md)，使用 [assets/learning-record.md](assets/learning-record.md) 的相关部分。保留目标与达标依据、来源、逐次尝试和恢复入口；一般讲解或单题只记录必要信息，不生成整套空表。

保存前先读已有记录，将本轮事实追加到对应任务，更新简短状态与下一次入口，保留历史回答及尚未完成的安排。暂停时保存待答题原文、相关材料位置和当前实际状态；接续时核对这些信息与本次请求。只保存成功后才报告路径；记录不存在或写入失败时如实说明，不宣称已恢复或已保存。

保存到用户指定或当前任务已经约定的输出位置；没有保存请求时，给聊天中的简短接续记录即可。学习进度属于用户的任务材料，不自动写回 Skill 或全局记忆。

## 跨 Agent 使用

使用宿主提供的资料读取、搜索和文件保存能力。缺少某项工具时说明限制，基于可用材料继续；没有文件保存能力时，在聊天中给出可复制的学习记录，不声称已经保存。跨会话接续需要可访问的记录；本 Skill 不依赖特定模型、插件或联网服务。

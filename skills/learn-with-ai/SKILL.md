# AI 学习实践

把本轮学习落到用户能够独立解释、判断或完成的一项表现。用实际作答决定下一步，让目标、材料、练习证据和下一次学习相互对应。沿用用户的语言、材料、工具和应用场景。

不确定一轮练习该是什么样子时，先看 [references/worked-example.md](references/worked-example.md)：一段从出题、答错、提示到留下记录的完整示范。

## 十步实践入口

以下保留原书十个步骤的名称，右侧为本 Skill 的简明原创实践约定。用户可按编号或名称调用；原书的具体提示词、图示和例子通过原文回看。

| 步骤 | 输入 | 本 Skill 的动作与产出 |
| --- | --- | --- |
| 1. 五视角STORM | 主题、应用问题与可用材料 | 从五个互补角度整理要研究的问题，形成观点与证据线索。 |
| 2. 矛盾图谱 | 不同说法及其出处 | 比较分歧与成立条件，列出冲突、依据和待核实问题。 |
| 3. 综合简报 | 调查与冲突分析结果 | 汇成当前判断，保留关键依据、联系和不确定之处。 |
| 4. 同行评审自检 | 当前简报及支持材料 | 检查结论是否得到支持，形成有依据的修订或保留意见。 |
| 5. 资源筛选 | 验收任务、基础与材料候选 | 选择服务当前缺口的材料，记录需要看的位置与练习用途。 |
| 6. 学习阶梯 | 验收标准与当前表现 | 从目标倒推前置能力，为每阶段安排可观察的练习证据。 |
| 7. 2小时啃下核心20% | 阶段安排与实际时间预算 | 安排新学、尝试和回看；需要长期保留时另列延迟复测计划。 |
| 8. 考到我崩溃 | 材料、验收条件及待检验能力 | 出题、等待真实作答，保留首次回答、提示与修订证据。 |
| 9. 费曼循环 | 待理解概念与学习者解释 | 对照解释的变化，检查因果、类比边界与新情境应用。 |
| 10. 一页速查表 | 已学内容、来源与实际错误 | 整理有来源的使用提示、能力证据、未解问题与下一次入口。 |

步骤名沿用原书以便对照。“2小时”“20%”“崩溃”是书中的叫法，实际时间、范围和题量以用户的预算和已有证据为准，也不构成效果保证；不对“多长时间掌握多少”作承诺。

用户要求按十步或完整流程学习、指定某一步、或从十步中途接续时，读取 [references/ten-step-workflow.md](references/ten-step-workflow.md)，按其中的衔接关系推进。指定某一步时直接定位该步，已有的前序工作直接复用。一般讲解或练习请求按下面的模式选取适合的环节。

## 选择这次怎么学

从上下文确定主题、要完成的任务、已有基础和时间约束。已经提供的信息直接沿用；只有缺失信息会改变下一步内容时才追问。主题尚未给出时，先问想学什么以及准备怎样使用；没给时间预算就按常规篇幅先开始。

按当前请求选择动作，不必走完所有模式：

- **只要计划或资料**：给能执行的安排、选择理由和可检查的完成表现。计划里的练习标为建议、保持未开始；交付计划后停下，是否开始练习由用户决定。
- **需要讲解**：先解释解决当前问题必需的概念；完全陌生时给一个小示例，再邀请用户尝试。用户只要答案或示范时，直接满足该请求。
- **需要练习或诊断**：利用现有材料出一道能区分具体理解问题的题，说明作答所需条件，然后等待回答。用户要求整套题时按指定形式提供。
- **继续学习或复习**：读取用户提供或当前项目已约定的记录，定位待答题、未解问题或到期复测，从记录停下的地方按当前请求接续。

开始一个学习任务时，用几句话明确**应用场景、最终任务、达标依据和允许的帮助条件**，已有信息直接复用。每项材料与练习都服务其中一项依据；能力证据来自作答与产物，阅读页数和完成阶段只算进度。基础未知就记为未知：用户愿意练习时用一次简短尝试确定起点，只要计划时按用户自述的基础安排。

例如，目标可以是“根据给定规则判断新案例并说明边界”；允许查规则但不接受 AI 解题提示时，按该条件判断独立性，不一概要求闭卷。操作任务同时说明需要看到什么产物或运行结果，纯口述不能替代实测。根据实际难度调整目标时，保留调整原因。

## 根据回答调整

交互练习通常一次一题。出题时说明任务条件和检查依据，然后停下等用户实际作答；答案、解析和支持材料的位置留到作答之后，反馈时再给出支持判断的材料位置。学习者的回答只能来自学习者：不代写，也不预演后续对话。用户要求提示时从少量线索开始，卡住再给分步帮助或示范；明确要解答时直接讲清。

收到回答后：

- 根据用户实际写出的理由、步骤或数字反馈。回答完整正确时，确认本题未发现实质缺口；没有可确认的正确部分时，直接指出主要误解；肯定点和错误都只写实际存在的，不硬凑。没有回答就没有掌握程度可评。
- 把“理解了规则”“能完成操作”“操作结果得到验证”分开。材料或实测不足时记为未知；表达流畅和自报会了都算不上通过的依据。
- 存在理解问题时，用相关的简短解释或提示帮助修订。
- 之后按本题表现与用户目标，改变一个有意义的条件继续验证，或结束本轮；已经答对的题不再要求改错。
- 根据表现补前置概念、缩小问题、增加难度或继续应用。反复卡住时先检查题意和材料是否清楚，再决定是否换题；题量跟着证据缺口走，不机械加题。

每次尝试标记一种学习表现：

| 状态 | 条件 |
| --- | --- |
| 独立完成 | 在约定条件下满足本题要求，且未用解题提示 |
| 提示后完成 | 借助提示、纠错反馈或答案示范后，自己作答达到要求 |
| 仍需练习 | 已作答，但未达到要求 |
| 仅看过示例 | 只看了示例或答案，还没有自己作答 |
| 尚未检验 | 未作答、未执行，也未看示例 |

每次尝试单独记一条，首次回答原样保留，修订追加在后。同一题得到过提示、纠错反馈或答案后的即时重做，最高记“提示后完成”，不能改记为独立完成；要检验独立性，换一道检验同一能力、未展示过解答的新题。经过真实间隔后的复测另记当次条件与表现，历史提示记录照旧保留。

需要诊断、费曼循环或持续记录时，读取 [references/practice-and-resume.md](references/practice-and-resume.md)。其中定义提示程度、来源定位、新题迁移、延迟复测与恢复记录的方法。**即时表现、延迟保持、迁移应用分别判断**；没测的维度保持“尚未检验”；一次答对只说明这一次，结论只说到证据覆盖的范围，不能据此宣布整个主题已掌握。需要评分时先给评分依据，没有依据时不给精确分数。

遵守用户要求的范围和可用时间。时间将尽、用户要求结束或本轮目标已有足够证据时，整理当前结果并结束本轮。提醒和定时任务只在用户明确要求时创建。

## 需要研究或选材时

已有材料足够支撑练习，就直接使用。需要调查陌生主题、处理相互矛盾的解释或选择学习资源时，再读 [references/evidence-review.md](references/evidence-review.md)。研究结果用来决定当前学什么、为什么；练习仍由用户完成。同一助手的多个角色或视角不算多份独立证据。

## 留下可继续的记录

本轮结束时给出实际做了什么、根据什么判断、还缺什么、下一次从哪里开始。按十步推进时，另记当前步骤、实际产物和跳过原因；步骤进度和掌握程度分开记。未作答的题、未执行的计划和未完成的真实测试保持原状态。

单轮学习、只在聊天里交付、或刚开始记录时，用 [assets/learning-record.md](assets/learning-record.md) 开头的“最小接续记录”即可。用户需要跨多次持续跟进、保存或导出时，读取 [references/practice-and-resume.md](references/practice-and-resume.md)，再按需展开模板的其余部分；一般讲解或单题只记必要信息。

保存前先读已有记录，把本轮事实追加到对应任务，更新简短状态与下一次入口；历史回答和尚未完成的安排原样保留。暂停时保存待答题原文、相关材料位置和当前实际状态；接续时核对这些信息与本次请求。保存成功后再报告路径；记录不存在或写入失败时如实说明，不宣称已恢复或已保存。以上保留做法是正常更新时的默认；用户明确要求删除或精简记录时照办，细则见 [references/practice-and-resume.md](references/practice-and-resume.md)。

保存到用户指定或当前任务已经约定的输出位置；没有保存请求时，给聊天中的简短接续记录即可。学习进度属于用户的任务材料，留在用户的文件里，不自动写回 Skill 或全局记忆。

## 跨 Agent 使用

使用宿主提供的资料读取、搜索和文件保存能力。缺少某项工具时说明限制，基于可用材料继续；没有文件保存能力时，在聊天中给出可复制的学习记录，并说明尚未保存。跨会话接续需要可访问的记录；本 Skill 不依赖特定模型、插件或联网服务。

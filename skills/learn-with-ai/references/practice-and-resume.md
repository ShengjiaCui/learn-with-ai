# 练习证据与暂停接续

用于诊断、费曼循环、复习或持续记录；只读本次需要的小节。五种学习状态和“首次回答原样保留”的约定以 SKILL.md 为准，这里补充提示程度、迁移、复测和保存的做法。完整的一轮示范见 [worked-example.md](worked-example.md)。

## 从目标生成可判定的题

从验收任务选择本次要检查的一项能力，说明题目条件、允许使用的材料和达标依据。缺少标准答案时先核对来源；来源矛盾或操作结果不可见时，说明哪些部分暂时无法评估。评分只用出题时说明过的依据。

操作任务保留用户实际产物与可见结果。用户贴出的代码可以审读，运行结果在实际运行前记为未知；助手代做的操作记为助手示范，不算用户独立完成的证据。用户口述的完成情况注明“用户自述”。

## 保留每次尝试

一题或一项任务用一个稳定标识，后续尝试另记时间和序号；规模小时用清楚的标题即可。

- 保留题目条件、来源定位与用户首次回答。短回答原文保存；长材料保留用户文件及位置，并忠实摘录关键部分。
- 记录实际给过的提示内容，以及用户是否已看到本题答案。下表的简写用于记录，教学对话里用平常话说即可。
- 修订追加在首次回答之后，注明改正依据和结果。

| 提示程度 | 含义 |
| --- | --- |
| H0 | 本次尝试没有解题提示或预先展示答案；允许的参考材料按任务约定，历史答案暴露另记 |
| H1 | 给出方向、关键条件或小线索 |
| H2 | 给出分步支架或部分解法 |
| H3 | 展示完整解答、直接改出结果或答案示范 |

一次尝试按实际用到的最高程度记录。同一题上此前给过的提示、纠错反馈或答案，都算进之后每一次即时重做；同一轮里最后一条回复没带提示，也不能降回 H0。H0 也可能答错；H3 之后、用户自己作答之前，状态是“仅看过示例”。纠错后要检验独立推导，换一道检验同一能力的等价新题；经过约定的真实间隔后可另开复测尝试，记录当次提示程度，历史答案暴露照旧保留。

## 从纠错走向迁移

反馈指出具体错因和材料依据，先补最小必要内容，再由用户重试。重试正确只说明本次纠错有效，独立性另测。

出新题时按实际目标改变一个有意义的条件，例如边界值、反例、假设或应用场景，并保持难度可比，不把尚未教过的另一项技能混入验收；只改表面数字不算新题。回答全对就确认全对，不强行挑错；已有证据足够就结束本轮，不机械凑题数。

费曼循环先收集学习者自己的解释，再根据实际内容选一个动作：澄清一个因果跳步、用普通语言重述、检查其所用类比的失效点，或在新情境中应用。保留解释前后的差异与依据，第二版解释仍由用户来写。完全陌生、确实需要事实输入时给小示范，之后请用户自己尝试。

## 将即时、延迟、迁移分开

这三项是不同的观察维度，不是必须同时通过的总分：

- **即时表现**：本轮在约定条件下做到了什么，给了什么帮助。
- **延迟保持**：经过实际间隔后，按目标用原题或等价新题进行无提示尝试。词义、事实等可用同一问题测回忆；检验独立推导宜用等价新题。记录前次时间、本次时间或可确认的间隔、历史答案暴露与本次是否再看答案。
- **迁移应用**：在变化后的情境里，是否独立完成目标任务；用了提示就按提示后的结果记录，不当作独立迁移。只换边界值或数字的同类新题计入即时表现；换到实际使用的情境才算迁移。

需要长期记住或未来使用时，建议下一次复测的时间或触发条件，并说明复测什么。间隔按预计使用时间、难度和本次表现调整，没有统一必用的“1、3、7 天”。一次即时失败可以先补练，一次即时成功也不等于长期保持已验证。

只有真实间隔已经发生、且符合本任务的复测安排，才记为延迟复测；时间信息不足时记“间隔未确认”。用户自述“几天后仍会”按自述记录，等实际作答再判断。工具模拟、预设回答和假设日期一律标注“模拟”，与用户真实进度分开。复测计划只写入学习记录；提醒或定时任务需要用户另行明确请求。

## 保存与恢复

有保存请求时，按 [../assets/learning-record.md](../assets/learning-record.md) 的相关部分更新已约定的文件：先读取原记录，追加本次尝试并更新摘要；其他主题、历史错误、旧证据和未到期的复测安排原样保留。方法或题目版本有变化时另作说明。完整聊天和来源全文无需保存。

以上保留规则（包括 SKILL.md 的“首次回答原样保留”）是正常更新时的默认做法。用户明确要求删除或精简某段原文时，以用户要求为准，按其保存范围执行，不为留证据而保留用户要删的原话。留下的摘要仍如实区分提示后与独立完成，删去后无法核对的部分标为“证据已删除”；删除不改变任何一次尝试的状态，也不把删除写成一次新的通过。

暂停时至少留下：目标与达标条件、当前步骤、最近证据、待答题原文、相关来源位置、下一动作、后续复测事项。刚出题就暂停时，该题记为未作答、步骤记“等待用户”，答案留到用户作答之后。只在聊天里交付时，用模板开头的“最小接续记录”格式，篇幅与本轮实际内容相称，并说明尚未保存到文件。

恢复时读取指定或本项目约定的记录与相关材料，简短确认上次停在哪、哪些结论有证据、现在接哪一步。优先接待答题或用户当前指定的事项，再按需要处理到期复测；模板占位符按“未记录”对待。来源规则已变时先核对受影响的条件，旧作答连同当时的版本一起保留。

旧记录缺字段时只补本次确实知道的信息。文件找不到时说明未能恢复，向用户索取路径或最小上下文；查找范围限于用户指定的位置和当前项目，不搜索无关的个人目录。历史只来自实际读到的记录，读不到的部分记“未记录”，不凭印象补出。用户选择暂时跳过时保留未完成状态和原因。

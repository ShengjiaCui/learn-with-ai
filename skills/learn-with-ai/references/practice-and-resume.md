# 练习证据与暂停接续

用于诊断、费曼循环、复习或持续记录。状态定义以 SKILL.md 为准；只读本次需要的小节。普通讲解、只要答案或只要计划时，不强制启动测试。

## 从目标生成可判定的题

从验收任务选择本次要检查的一项能力，说明题目条件、允许使用的材料和达标依据。缺少标准答案时先核对来源；来源矛盾或操作结果不可见时，明确哪些部分暂不能评估。题目和评分都服务同一目标，不在作答后临时追加隐藏要求。

操作任务保留用户实际产物与可见结果。用户贴出的代码可以审读，但未运行就保留运行结果未知；助手代做的操作不是用户独立完成的证据。对用户口述的完成情况注明“用户自述”，不写成助手已经验证。

## 保留每次尝试

一题或一项任务保留一个稳定标识，后续尝试另记时间和序号；规模小时用清楚的标题即可，不要求数据库。

- 保留题目条件、来源定位与**用户首次回答**。短回答可原文保存；长材料保留用户文件及位置，并忠实摘录关键部分。
- 记录实际给过的提示内容，以及用户是否已看到本题答案。可以使用以下简写，向用户教学时不必展示代码。
- 后续修订追加记录，注明改正依据和结果；不要用正确的最终答案覆盖原错误。

| 提示程度 | 含义 |
| --- | --- |
| H0 | 本次尝试没有解题提示或预先展示答案；允许的参考材料按任务约定，历史答案暴露另记 |
| H1 | 给出方向、关键条件或小线索 |
| H2 | 给出分步支架或部分解法 |
| H3 | 展示完整解答、直接改出结果或答案示范 |

使用本次尝试实际得到的最高程度，不能因为同一轮的最后一次回复未给提示就降回 H0。H0 仍可能答错；H3 后还没有自己作答时只算看过示范，不能自动标为通过。即时重做同题沿用答案暴露记录；纠错后若要检验独立推导，换成检验同一能力的等价新题。经过约定的真实间隔后，可另开复测尝试记录当次提示程度，历史暴露仍保留。

## 从纠错走向迁移

反馈指出具体错因和材料依据，先补最小必要内容，再由用户重试。重试正确表示本次纠错结果；需要验证独立性时换一道没有展示过解答的新题，而不只改表面数字。

按实际目标改变有意义的条件，例如边界值、反例、假设或应用场景；同时保持难度可比，不把尚未教过的另一项技能混入验收。全对回答不强行挑错；已有证据足够就结束本轮，不机械凑题数。

费曼循环先收集学习者自己的解释，再根据实际内容选择动作：澄清一个因果跳步、用普通语言重述、检查其所用类比的失效点，或在新情境中应用。保留解释前后的差异与依据，不替用户完成第二版解释。完全陌生、确实需要事实输入时给小示范，之后仍需用户自己尝试。

## 将即时、延迟、迁移分开

这三项是不同的观察维度，不是必须同时通过的总分：

- **即时表现**：本轮在约定条件下做到了什么，给了什么帮助。
- **延迟保持**：经过实际间隔后，按目标用原题或等价新题进行无提示尝试。词义、事实等可用同一问题测回忆；需要检验独立推导时宜用等价新题。记录前次时间、本次时间或可确认的间隔、历史答案暴露与本次是否再看答案。
- **迁移应用**：在变化后的情境里，是否独立完成目标任务；如果使用了提示，保留提示后结果，不当作独立迁移。

需要长期记住或未来使用时，建议下一次复测的时间或触发条件，并说明复测什么。间隔按预计使用时间、难度和本次表现调整；没有统一必用的“1、3、7 天”。一次即时失败可先补练，一次即时成功也不等于长期保持已验证。

计划日期不等于已发生。只有真实间隔已发生且符合本任务的复测安排，才记为延迟复测；同一轮即时重答不能冒充。时间信息不足时保留未确认。用户只自述“几天后仍会”时记录自述，等实际回答再判断。工具模拟、预设回答和假设日期都明确标作模拟，不能进入用户真实进度。复测计划只写入学习记录；创建提醒或定时任务需要另有明确请求。

## 保存与恢复

保存请求下，按 [../assets/learning-record.md](../assets/learning-record.md) 的相关部分更新已约定文件。先读取原记录，追加本次尝试并更新摘要；不要覆盖其他主题、历史错误、旧证据或尚未到期的复测安排。新方法或题目版本的改变另作说明。无需保存完整聊天或所有来源全文。

以上是正常更新时的保留规则。用户明确要求删除或精简某段原文时遵从其保存范围；保留下来的摘要仍须如实区分提示后与独立完成，证据删去后不可核对的部分标明缺失。不要为了保留证据强行保留用户要求删除的原话，也不把删除改写成一次新的通过。

暂停至少留下：目标与达标条件、当前步骤、最近证据、尚待回答的题目原文、相关来源位置、下一动作、后续复测事项。刚出题就暂停时，该题仍是未作答，步骤可记“等待用户”；不要顺手附答案。

恢复时读取指定或本项目约定的记录与相关材料，简短确认上次停在哪、哪些结论有证据、现在接哪一步。优先接待答题或当前用户指定的事项，再按需要处理到期复测；不重新跑全部步骤，也不把模板占位符当作事实。来源规则已变则先核受影响条件，保留旧作答及其当时版本。

旧记录少字段时只补本次确实知道的信息。文件找不到时说明未能恢复，索取路径或最小上下文；不搜索无关个人目录，也不凭印象补出历史。用户选择暂时跳过时保留未完成状态和原因。
